# Drift-Sense: SEM Navigation Error Recovery using Siamese Heatmap Networks

This repository contains the submission for the **SEMICON India 2026: Applied Materials Drift-Sense Hackathon**. 

## Project Overview

Scanning Electron Microscopes (SEMs) often suffer from stage drift, causing a misalignment between the expected navigation coordinates and the actual field of view. This problem is particularly challenging when imaging highly repetitive structures like DRAM arrays, leading to the "Infinite Waldo" problem: finding a specific matching pattern in a sea of identical patterns.

**Drift-Sense** solves this by using a Fully Convolutional Siamese Network (FCN) designed to predict robust 2D spatial heatmaps instead of raw coordinates. 

### Key Innovations:
- **Spatial Heatmap Prediction:** Overcomes the "mode collapse" issue common with coordinate regression (MSE) on repeating patterns by generating a probabilistic distribution (heatmap) of the target location.
- **Fingerprinted Synthetic Dataset:** Introduces physically realistic low-frequency blob noise and random contact drops to simulate realistic wafer imperfections, making local patterns uniquely distinguishable.
- **Memory-Optimized Architecture:** Downscales input images internally and uses a lightweight VGG-style backbone to process massive 1000x1000 inputs within a strict 8GB VRAM limit (batch size 16).

## Repository Structure

```
├── dataset_generator.py   # Generates the synthetic SEM dataset with unique structural "fingerprints"
├── model.py               # Defines the Fully Convolutional Siamese Network (DriftSenseNet)
├── train.py               # Training loop using Spatial Cross-Entropy and Gaussian target heatmaps
├── eval.py                # Evaluates model accuracy (Euclidean pixel error) on the generated dataset
├── visualize.py           # Visualizes the model's predictions (bounding boxes) and raw heatmaps
├── inference.py           # Standalone hackathon inference script for evaluation
├── gravnet_weights.pt     # Pre-trained model weights (auto-generated by train.py)
└── README.md              # Project documentation
```

- numpy

- tqdm

### Installation
Clone the repository and install the required dependencies:
```bash
git clone https://github.com/Mukesh747830/drift-sense-gravnet.git
cd drift-sense-gravnet
pip install torch torchvision pillow numpy pandas opencv-python matplotlib tqdm
```

## Usage Instructions

### 1. Generate the Dataset
Create the synthetic training dataset (5000 image pairs). This will generate a `dataset/` folder containing `search/` and `reference/` images along with `labels.json`.
```bash
python dataset_generator.py
```

### 2. Train the Model
Train the Siamese Network. The script will save the trained weights to `gravnet_weights.pt` in the root directory.
```bash
python train.py
```

### 3. Evaluate and Visualize (Optional)
Run evaluation to calculate Euclidean pixel errors across the dataset.
```bash
python eval.py
```
To visualize the predicted heatmap and bounding box for a single sample:
```bash
python visualize.py
```

### 4. Run Standalone Inference (Hackathon Evaluation)
Use the `inference.py` script to run the model on a new test dataset. 
The input directory must contain two subdirectories: `search/` and `reference/`. The script will output a `predictions.csv` file in the specified output directory.

```bash
python inference.py --input_dir path/to/test/dataset --output_dir path/to/save/results
```
- `--input_dir`: Path to the test directory (must contain `search` and `reference` subfolders with identical filenames).
- `--output_dir`: Path where the `predictions.csv` will be saved.

## Architecture Highlights
- **Backbone**: 2-stage lightweight CNN with stride 4.
- **Matching**: Depth-wise cross-correlation of pooled reference features with the search feature map.
- **Loss Function**: Spatial Cross-Entropy against a normalized 2D Gaussian ground truth target.
- **Inference Extraction**: Sub-pixel `argmax` extraction mapped back to the original 1000x1000 coordinate space.
